Project Name:
Alzikrayat


Project Description:
Alzikrayat is a project designed for storing and sharing memories through photos. Multiple users can use the application and upload their photos after registering and logging in with their own accounts.
The application provides a photo gallery where users can view photos and add comments. Users can also upload new photos, while only the owner of a photo is authorized to delete it.

MySQL  
PyMySQL

CSS3  
JavaScript  
Bootstrap

python-dotenv  
Git  
GitHub


How to Run:
Go to the project folder, then run the run.py file using the following command in terminal:
python run.
and open this url in browser http://127.0.0.1:5000/
